공개 위치 / 공개 레코드 개

공개 위치는 소비자가 받았거나 처리했다는 뜻이 아닙니다. 소비자의 대기 목록·요약·문서 생성·처리 완료는 이 시스템에서 추적하지 않습니다.

인증된 Pull 연결

이 계획만 조회하는 상대 API 주소

API 요청에 Authorization: Bearer 헤더가 필요합니다. API 자격은 운영자에게 별도로 받으세요. 관리자 세션은 API 자격을 대신하지 않습니다.

최초 after=0, limit=1~100. 응답 nextAfter를 소비자가 보관해 다음 요청의 after로 보냅니다. 같은 위치를 다시 조회할 수 있으며 소비자가 중복 처리를 방지해야 합니다.
