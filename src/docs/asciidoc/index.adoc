이 문서는 실제 애플리케이션과 H2 데이터베이스를 사용하는 테스트에서 생성합니다.
요청 또는 응답 필드가 문서와 달라지면 REST Docs 테스트가 실패합니다.
예시의 `https://api.example.com`은 설명용 주소이며 로컬 실행 주소는 `http://localhost:8080`입니다.

== 제공 범위와 인증

현재 구현은 수집원과 수집 작업의 설정을 저장하고 조회하는 관리 API입니다.
주식, 경제, 시사, 개발 등의 분야는 별도 열거형으로 제한하지 않으며 이름, 대상 경로와 매개변수로 구분합니다.
`HTTP_JSON`, `RSS_ATOM`, `HTML`은 수집원 분류입니다. 해당 유형의 실제 HTTP 요청, 파싱 및 브라우저 실행은 아직 구현하지 않았습니다.

* 모든 `/api` 요청에 `Authorization: Bearer <SCRAPING_API_TOKEN>` 헤더가 필요합니다.
* 운영 토큰은 환경변수 `SCRAPING_API_TOKEN`으로 설정합니다. 아래의 `test-operator-token`은 테스트 문서용 값입니다.
* 인증 누락 또는 잘못된 토큰은 `401`, 서버 토큰 미설정은 `503`을 반환합니다.
* 현재 토큰은 단일 운영자용입니다. 사용자별 계정과 데이터 접근 범위는 제공하지 않습니다.

`enabled`는 향후 실행기가 참고할 설정값입니다. `true`로 바꾸어도 현재 버전에서는 수집을 시작하지 않습니다.
스케줄러, 실행 이력과 수집 결과의 저장, 재시도, 중복 제거, 증분 수집은 구현 범위에 포함되지 않습니다.
향후 외부 요청을 구현할 때 네트워크 접근 범위, 사이트별 정책과 요청 제한을 함께 적용해야 합니다.

수집원 URL과 작업 매개변수는 평문 설정으로 저장되고 조회됩니다. 비밀번호, API 키, 인증 토큰을 넣지 않습니다.
`credentialRef`에는 외부 비밀 저장소의 키로 사용할 식별자만 보관합니다. 현재 버전은 비밀 값을 조회하거나 사용하지 않습니다.

== 수집원 생성

수집원은 이름, 입력 유형과 기준 URL을 정의합니다. 생성 후 수집원 수정과 삭제는 제공하지 않습니다.
이름은 앞뒤 공백을 제거한 뒤 1~120자여야 합니다.
기준 URL은 최대 2048자의 절대 HTTP(S) 주소여야 하며 호스트가 필요합니다.
사용자 정보, 쿼리 문자열과 프래그먼트는 허용하지 않습니다. 명시한 포트는 1~65535여야 합니다.
`credentialRef`를 지정하면 영문자, 숫자, 점, 밑줄, 하이픈으로 구성된 1~120자여야 합니다.

== 수집 작업 생성

수집 작업은 기존 수집원, 대상 경로와 매개변수, 반복 간격을 묶습니다.
작업은 항상 `enabled=false`, `version=0`으로 생성됩니다.

대상 경로는 하나의 `/`로 시작하는 최대 2048자 문자열입니다.
공백, `?`, `#`, 역슬래시 및 `..` 경로 구간은 허용하지 않습니다.
쿼리 매개변수는 `parameters`에 최대 50개를 지정합니다. 키는 공백만으로 구성할 수 없는 1~100자이며 값은 최대 2000자 문자열입니다.
작업 설정에는 스크립트나 실행 코드를 받지 않습니다.

`everySeconds`는 `60~31536000`초, 즉 1분~365일입니다.
`anchorAt`은 반복 간격의 기준 시각이며 ISO 8601 UTC 형식으로 응답합니다. 저장 가능한 시각은 1970년~9999년입니다.
도메인의 다음 실행 시각 계산은 기준 시각의 간격을 유지하며 주어진 시각보다 엄격히 이후인 첫 슬롯을 선택합니다.
기준 시각 전에는 기준 시각을 반환하고, 놓친 슬롯은 재생하지 않습니다. 현재 API가 실행 예약을 등록하지는 않습니다.

== 수집 작업 설정 교체

`definition` 전체를 전달합니다. 생략한 기존 설정을 부분적으로 유지하지 않습니다.
활성화 상태와 생성 시각은 유지됩니다.
마지막으로 조회한 `version`을 `expectedVersion`에 전달해야 하며 성공하면 버전이 1 증가합니다.
다른 요청이 먼저 변경했다면 `409`를 반환하고 저장된 설정은 덮어쓰지 않습니다. 다시 조회한 뒤 변경을 검토하여 재요청합니다.

== 오류

입력 오류는 `400`, 존재하지 않는 수집원이나 작업은 `404`, 작업 버전 충돌은 `409`로 응답합니다.
오류 본문은 `application/problem+json` 형식입니다. 잘못된 JSON, UUID, 열거형과 필수 값 누락도 `400`입니다.
