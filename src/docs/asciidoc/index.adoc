로컬 요청에서는 예시의 `https://api.example.com`을 `http://localhost:8080`으로 바꿉니다.

== 제공 범위와 인증

모든 `/api` 요청에 `Authorization: Bearer <SCRAPING_API_TOKEN>`을 보냅니다.
토큰 미설정은 503, 누락·불일치는 401입니다. 단일 운영자용이며 사용자별 데이터 분리는 없습니다.
문서 예시의 test-operator-token은 테스트용입니다. URL·매개변수에 비밀값을 넣지 않습니다.
실제 커넥터·주기 워커·실행 이력·수집 결과 저장은 구현하지 않았습니다.
