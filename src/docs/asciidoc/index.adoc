이 문서는 실제 애플리케이션과 데이터베이스를 사용하는 테스트에서 생성합니다.
요청 또는 응답 필드가 문서와 달라지면 REST Docs 테스트가 실패합니다.
예시의 `https://api.example.com`은 설명용 주소이며 로컬 실행 주소는 `http://localhost:8080`입니다.
