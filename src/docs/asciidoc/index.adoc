로컬 요청에서는 예시의 `https://api.example.com`을 `http://localhost:8080`으로 바꿉니다.

== 제공 범위와 인증

모든 `/api` 요청에 `Authorization: Bearer <SCRAPING_API_TOKEN>`을 보냅니다.
토큰 미설정은 503, 누락·불일치는 401입니다. 단일 운영자용이며 사용자별 데이터 분리는 없습니다.
문서 예시의 test-operator-token은 테스트용입니다. URL·매개변수에 비밀값을 넣지 않습니다.
HTTP_JSON만 수집하며 RSS_ATOM·HTML은 실행이 FAILED입니다. enabled=true면 다음 슬롯부터 주기 실행하고, credentialRef가 있는 출처는 FAILED입니다.

== 계획별 pull export

기본 비활성이다. Bearer 인증을 사용하며 push 목적지는 없다. `after=0`부터 기존 성공 레코드까지 포함해 읽는다.
`limit`은 1~100, 기본 20이다. 반환 `nextAfter`를 다음 요청의 `after`로 보내며 빈 페이지에서도 같은 위치로 다시 poll한다.
순번은 공개 원장 위치이며 원천 체크포인트나 소비자 처리 완료 위치가 아니다. 수신기가 중복 억제와 자신의 처리 위치를 저장한다.

=== 즉시 실행

멱등 키는 계획별 영숫자·점·밑줄·하이픈 1~120자다. 같은 키·버전은 기존 실행을 반환하며 다른 버전 재사용은 409다.
비활성 계획도 명시적으로 실행할 수 있다. 요청은 PENDING 실행을 만들고 워커가 실행하므로 응답은 수집 완료를 뜻하지 않는다.
